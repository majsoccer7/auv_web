# WIRED Underwater Robotics

Redesign of the Texas A&M WIRED AUV team site, staged on Cloudflare Workers.

Repo: https://github.com/tqdesign/wired-auv

Original Wix site: [reaftamu.wixsite.com/website](https://reaftamu.wixsite.com/website)

## Local

```bash
npm install
npx wrangler dev
```

Open http://localhost:8787

## Deploy

```bash
npx wrangler deploy
```

Staging: https://wired-auv.tqdesign.workers.dev

Custom domain comes later.

## Content

Pages and photos were copied from the live Wix site (home, join, FAQ, team, vehicles, gallery, achievements, sponsors, contact). A few older Wix originals returned 403; those are called out as we iterate.
