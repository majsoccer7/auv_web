Mechanical

  • PVC pipe hull with a polycarbonate dome
  • Electronics prism, hollowed to run wiring
  • Eight Blue Robotics T200 thrusters
  • Electronic arm, two torpedo launchers, and a marble dropper
  • Watertight hull; casings for components that were not

Electrical

  • Intel NUC, ATX power supply, Arduino Uno, Adafruit PWM driver, and PCB
  • Serial commands from the NUC to thrusters and servos via Arduino
  • VectorNav VN-100 AHRS for orientation
  • Four 4S 10,000 mAh batteries

Programming

  • OpenCV for real-time object position estimates
  • Arduino receives object and sensor data to command thrusters
  • Software written in Python with recursive real-time control
