Mechanical

  • Trained members in SolidWorks and Fusion 360
  • Taught manufacturing methods and how to read engineering drawings
  • Revised structural components, including a custom-fit bottom panel
  • New encaps for internally mounting a stereo vision camera
  • Midcap interchangeable panels for more functionality
  • Maneuvering arm and dropper designed for task completion

Electrical

  • Jetson TX2 as the main computer
  • Fuses for ESCs and other components
  • Custom PCB for ESC functions
  • Upgraded watertight kill switch and mission switch
  • Higher-voltage batteries and battery monitoring
  • Teensy microcontroller and custom shield for sensors
  • Hydrophone subsystem with Aquarian H2A hydrophones

Programming

  • Python, C++, and OpenCV onboarding
  • ROS system integration
  • Machine learning for object detection
  • Image processing and motion control for competition tasks
